## Selected Projects

### Madar — AR Indoor Navigation
`Flutter` · `Dart` · `Firebase`

Indoor navigation combining interactive 3D maps and AR for multi-floor environments. Implemented A*-based routing, path preferences, one-way escalator handling, nearest-service recommendations, and location sharing.

### RAGBAN — 3D Time-Switching Puzzle Game
`Unity` · `C#` · `Blender`

A Saudi-inspired puzzle game featuring instant Past/Present switching and interconnected environmental puzzles. Developed gameplay systems, integrated 3D environments and AI-assisted assets, and prepared a WebGL build.

### Traffic Density Classifier
`Python` · `Computer Vision` · `Deep Learning`

Trained and evaluated CNN and ResNet-50 models on **4,054 manually labeled traffic images**. An optimized custom CNN achieved **91.09% test accuracy** and a **0.90 macro F1-score**.
